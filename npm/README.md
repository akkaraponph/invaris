# Invaris

Invaris is a verification CLI. See the [installation guide](https://github.com/refactorroom/invaris/blob/main/docs/installation.md) and [project documentation](https://github.com/refactorroom/invaris).

Requires Node.js 22.14 or later and Linux or macOS on x64 or arm64. On Windows, use WSL. The package includes the command provider and does not download binaries during installation.
