## Keep GitHub Pages current

- Before finishing any change, review `docs/index.html` and its relevant linked references for documentation impact.
- Update the site in the same change whenever it affects user-facing behavior, CLI commands or flags, configuration, report schemas, examples, prerequisites, or supported capabilities. Put detailed changes in the linked reference and update the landing page when its overview, quick start, or links are affected.
- Before handing off, run any commands you changed in the docs and check that updated links resolve. If the docs already match the change, no documentation edit is needed.
