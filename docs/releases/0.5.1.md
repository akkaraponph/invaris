# Invaris v0.5.1

- Run a full suite and select its reported test IDs with repeatable `test-result --test-id ID`. Missing selected tests produce an inconclusive result.
- Use `validity-result tsc` to distinguish recognized TypeScript source errors from compiler setup failures during mutation validation.
- Use per-action help and read failed mutation stage details in `explain`.
- Follow the refreshed documentation homepage for installation and a runnable guard challenge.

Existing harnesses and default evidence versions remain supported. The explanation schema adds an optional `details` field. Review [installation](../installation.md) and the [harness reference](../harness-spec.md).
